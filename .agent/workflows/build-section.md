# Workflow: Build Section from UI/UX

Pasos para construir una sección basada en referencias:

1.  **Paso 1: Análisis**
    - Lista los archivos encontrados en `carpeta ui\ux`.
    - Describe brevemente qué diseño interpretas de ellos.

2.  **Paso 2: Desarrollo**
    - Genera el código del componente en `src/components/sections/`.
    - Asegúrate de exportarlo correctamente.

3.  **Paso 3: Implementación**
    - Muestra cómo importar y colocar ese componente en `src/app/page.tsx`.
